# 蘇映霖 | 個人作品集

以 SQL 資料查詢、Power BI 報表製作與資料整理為主的作品集。  
目前主要使用 SQL、Power BI、Power Query 與 DAX 進行資料處理與視覺化。

---

## [01｜E-Commerce Sales 儀表板](./E-Commerce%20Sales/)

以 Kaggle E-Commerce Sales 資料集為基礎，使用 Pandas 進行資料清理並輸出 CSV，
並透過 SQL Server 與 Pandas 進行資料品質檢查及多表分析，最後利用 Power BI 製作銷售、客群與 RFM 分群儀表板。

`SQL Server` `Pandas` `Power BI` `DAX`

## [02｜歐洲足球五大聯賽分析儀表板](./FootballDashboard/)

這份作品為職訓班的 Power BI 期末專題報告。
主題為整合 2018/19-2023/24 賽季之歐洲五大足球聯賽相關資料。
建立含五大聯賽總覽到聯賽、俱樂部層級的數據總覽，以及個人球員的轉會紀錄及市場估值變化。

## [03｜飯店預訂與取消率分析儀表板](./HotelDashboard/)

使用 Hotel Booking Demand 資料集分析飯店訂房與取消情況。
從取消率、提前預訂時間、飯店類型與客群等面向建立互動式 Power BI 報表。
